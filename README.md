# 22-QUIZ-APP-IN-REACT


A simple and interactive Quiz Application built using React.  
This project demonstrates component-based architecture, state management using React Hooks, score tracking, and quiz result handling.


 Features

 Multiple choice quiz questions
 Component-based architecture
 Question component
 Score tracking system
 Results screen
 Restart quiz functionality
 Responsive UI
 React Hooks (`useState`) for state management


 Tech Stack

 React
JavaScript (ES6)
 CSS3
